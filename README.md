# Celsius Investment Banking Project Website

This is a static portfolio website for Wendy Chen's MGT 185 Investment Banking project.

## How to use

1. Open `index.html` in your browser.
2. Replace `YOUR_EMAIL_HERE` in `index.html` with your real email.
3. Replace the mockup section with screenshots from your Excel model, DCF, LBO, or final presentation.
4. Upload the folder to GitHub Pages, Netlify, Vercel, Wix custom code, or any static hosting platform.

## Files

- `index.html` controls the content.
- `styles.css` controls the design.
